# Приглашения Пользователей

Раздел «Пригласить друга» в личном кабинете отделен от каталога реферальных
ссылок бирж. Доступен всем зарегистрированным активным пользователям.

## Ссылки И Коды

- Формат: `https://t.me/<bot_username>?start=r_<code>`.
- Код выдается автоматически: ровно **5 символов `a-z` и `0-9`**, обязательно
  хотя бы одна буква и одна цифра. Используется криптографический `secrets.choice`.
  Telegram ID и порядковый номер пользователя в ссылку не включаются.
- Ввод, изменение и самостоятельная генерация нового кода пользователю недоступны.
  Старые кнопки выбора своего кода отключены, обработчиков ввода нет.
- Код постоянный; повторное открытие раздела не меняет его.
- Коллизии обрабатываются повторной генерацией; уникальность контролирует БД.
- Старые длинные коды заменяются короткими при открытии личного раздела.
  Прежние ссылки сохраняют владельца и продолжают работать как алиасы.
- Код публичный, предназначен только для приглашений, не для авторизации.

## Приглашения

Пригласивший закрепляется только при первой регистрации нового пользователя
через `/start` в личном чате. Обработчик использует разобранный `CommandObject`,
а не самостоятельный парсинг строки команды.

Повторные переходы не меняют реферера. Существующий пользователь без реферера
также не может быть присвоен. Самоприглашение запрещено; цепочки не образуют
циклов, поскольку реферер уже существует, а приглашенный обязательно новый.

Недействительная ссылка не блокирует обычную регистрацию, но приглашение не
засчитывается; при последующем переходе пользователь уже считается существующим.
Ссылки заблокированного владельца не создают новую привязку. Переход из группы
или через `/cabinet` не создает реферальной привязки.

В личном разделе показаны число приглашенных и число приглашенных с активными
UID. Несколько UID одного приглашенного не увеличивают второй счетчик повторно.
Чужие Telegram ID, UID, кошельки и балансы в этом разделе не показываются.

## Хранение

Миграция `d9258e73b014` после `c8147d62a903` добавляет `invite_codes` и
`invite_attributions`. Уникальность имен и одной основной ссылки контролирует БД;
на приглашенного допускается ровно одна привязка. Регистрация и аудит сохраняются
одной транзакцией; PostgreSQL `ON CONFLICT` и блокировки защищают от гонок.
Коллизия при автоматическом обновлении старого кода не удаляет рабочую ссылку.
Формат прежних алиасов сохраняется для обратной совместимости; все вновь
сгенерированные коды строго пятисимвольные.

Откат миграции при наличии выданных ссылок запрещен, чтобы не удалить привязки.
Партнерские вознаграждения описаны отдельно в `REFERRAL_REVENUE_SHARE.md`:
семь рангов, 20-50% нового сбора владельца, отдельный баланс и вывод.
Рефбек приглашенного не уменьшается. История первоначального выпуска ниже
относится к версии, где были только ссылки и учет приглашенных.
