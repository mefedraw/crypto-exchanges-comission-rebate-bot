# Payout DB Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the PostgreSQL persistence layer for the payout bot — SQLAlchemy 2.0
async models for the 11 tables in `DB_SCHEMA.md`, an Alembic migration, and constraint
tests that prove the money-safety invariants hold at the DB level.

**Architecture:** A new `bot/db/` package: async engine/session, a `DeclarativeBase`, and
typed models grouped by domain (identity / ledger / payouts / ops). Alembic autogenerates
one migration from the models. Tests run against an ephemeral PostgreSQL (`testcontainers`)
so Postgres-specific constraints are exercised for real.

**Tech Stack:** Python 3.11+, SQLAlchemy 2.0 (async) + asyncpg, Alembic, pydantic-settings,
pytest + pytest-asyncio, testcontainers[postgresql].

## Global Constraints

- Money columns are `Numeric(38, 18)` — never float. (CLAUDE.md, DB_SCHEMA.md)
- Full type annotations; `mypy` strict must pass on `bot/`. (CLAUDE.md)
- `ruff check` and `ruff format --check` must pass. Run `uv run ruff format <files>` before every commit (the toolchain may emit tab indentation).
- Test command: `uv run python -m pytest` (NOT bare `pytest`).
- **Tests require Docker running** (testcontainers spins up PostgreSQL 16). Postgres-specific features (native ENUM, JSONB, partial-unique indexes, `Numeric(38,18)`) must be tested on real Postgres, not SQLite.
- Table/column names and constraints must match `DB_SCHEMA.md` exactly (it is the source of truth). Key invariants the DB must enforce: `UNIQUE(exchange, uid)`; one active wallet per user (partial unique); `payouts.idempotency_key` unique; one active nonce per `payouts` (partial unique); an accrual belongs to at most one payout.
- `REBATE_EPOCH` and accrual/backfill logic are OUT OF SCOPE here (they belong to the accrual-worker plan). This plan builds only schema + models + migration.

```python
# bot/db/models/identity.py
"""Users, wallets, exchange-account (UID) models. See DB_SCHEMA.md §1."""

from __future__ import annotations

from datetime import date, datetime

from sqlalchemy import (
    BigInteger,
    Date,
    DateTime,
    Enum,
    Index,
    LargeBinary,
    String,
    UniqueConstraint,
    func,
    text,
)
from sqlalchemy.orm import Mapped, mapped_column

from bot.db.base import Base

user_role = Enum("user", "dev", "admin", name="user_role")
user_status = Enum("active", "blocked", "manual_review", name="user_status")
wallet_status = Enum("active", "replaced", "disabled", "admin_hold", name="wallet_status")
account_status = Enum("active", "blocked", "archived", name="account_status")


class User(Base):
    __tablename__ = "users"

    id: Mapped[int] = mapped_column(BigInteger, primary_key=True)  # telegram_user_id
    role: Mapped[str] = mapped_column(user_role, nullable=False, server_default="user")
    status: Mapped[str] = mapped_column(user_status, nullable=False, server_default="active")
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), nullable=False, server_default=func.now()
    )
    updated_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), nullable=False, server_default=func.now()
    )


class Wallet(Base):
    __tablename__ = "wallets"

    id: Mapped[int] = mapped_column(BigInteger, primary_key=True, autoincrement=True)
    user_id: Mapped[int] = mapped_column(BigInteger, nullable=False)
    chain: Mapped[str] = mapped_column(String, nullable=False, server_default="BEP20")
    address_encrypted: Mapped[bytes] = mapped_column(LargeBinary, nullable=False)
    address_hash: Mapped[bytes] = mapped_column(LargeBinary, nullable=False)
    address_masked: Mapped[str] = mapped_column(String, nullable=False)
    status: Mapped[str] = mapped_column(wallet_status, nullable=False, server_default="active")
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), nullable=False, server_default=func.now()
    )
    replaced_at: Mapped[datetime | None] = mapped_column(DateTime(timezone=True))

    __table_args__ = (
        Index(
            "uq_wallet_active",
            "user_id",
            unique=True,
            postgresql_where=text("status = 'active'"),
        ),
        Index("ix_wallet_hash", "address_hash"),
    )


class ExchangeAccount(Base):
    __tablename__ = "exchange_accounts"

    id: Mapped[int] = mapped_column(BigInteger, primary_key=True, autoincrement=True)
    user_id: Mapped[int] = mapped_column(BigInteger, nullable=False)
    exchange: Mapped[str] = mapped_column(String, nullable=False)
    uid: Mapped[str] = mapped_column(String, nullable=False)
    status: Mapped[str] = mapped_column(account_status, nullable=False, server_default="active")
    # = REBATE_EPOCH or later; set by the accrual-worker layer (business 3.2).
    accrual_since: Mapped[date] = mapped_column(Date, nullable=False)
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), nullable=False, server_default=func.now()
    )

    __table_args__ = (
        UniqueConstraint("exchange", "uid", name="uq_exchange_uid"),
        Index("ix_exch_acc_user", "user_id"),
    )
```
