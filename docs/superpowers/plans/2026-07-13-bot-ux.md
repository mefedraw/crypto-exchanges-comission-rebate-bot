# Phase 4 — Bot UX (self-service payout) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A self-service Telegram cabinet: users manage their payout wallet and exchange UIDs, view stats/balance/rank, and initiate a withdrawal that reserves accruals and creates a `payouts(status=reserved)` row (the actual on-chain send is Phase 5).

**Architecture:** New `bot/botui/` package. A per-update `DbSessionMiddleware` opens one AsyncSession per update (commit on success / rollback on error). Thin aiogram handlers delegate to a `service` layer over an async `repository`; money-touching logic (balance FIFO, reserve, single-use action_token) is verified against real Postgres (testcontainers). Ranks/fees reuse `bot/payout/`.

**Tech Stack:** aiogram 3.13.1 (Router, StatesGroup/State, FSMContext, CallbackData, InlineKeyboardBuilder, MemoryStorage in tests), SQLAlchemy 2.0 async + asyncpg + Postgres, pydantic, Decimal-only money, pytest-asyncio (`loop_scope="session"`), cryptography.Fernet (reuse `SecretCipher`).

## Global Constraints

- **Money is `Decimal` only**; accounting asset USDT. Never float, never sum non-USDT.
- **Whitelist is already global** (`WhitelistMiddleware`, outer). Identify the user ONLY from `message.from_user.id` / `callback.from_user.id` (== `users.id` == telegram id). NEVER trust an id from callback-data.
- **No secrets in logs.** Wallet address stored encrypted (Fernet via `SecretCipher`), shown masked (`0xABCD…1234`). Never log the plaintext address or tokens.
- **Address validation (owner-decided): format only** — `^0x[0-9a-fA-F]{40}$`. No keccak/EIP-55, no new dependency. Normalize to lowercase for `address_hash` lookup; store the address as entered (lowercased) encrypted.
- **action_token (owner-decided): TTL 5 minutes, single-use.** Consume is an atomic `UPDATE action_tokens SET state='used', used_at=now() WHERE token=:t AND state='issued'` — only the row-returning caller proceeds. On consume, re-validate the reserved accrual set is still fully `available`; if drift, abort softly.
- **Withdraw semantics (owner-decided):** flow ends at `payouts(status='reserved')` + accruals `available`→`reserved`. Phase 5 sends. A user with an active `reserved` payout cannot start another withdrawal (cooldown is anchored to a *successful send*, which is Phase 5 — not to the reserve).
- **Cooldown / rank / min-payout** reuse `bot/payout/`: `ranks.effective_rank`, `ranks.rank_for_gross`, `ranks.fee_pct`, `ranks.cooldown_days`, `expiry.next_withdrawal_allowed`, `MIN_PAYOUT_USDT = Decimal("10")`.
- **Every inline callback answers** (`await callback.answer()`) to clear the client spinner; stale/invalid tokens or states get a soft reply, never an exception.
- Tests: real Postgres for repository/service; handlers tested by calling handler fns directly with fake `Message`/`CallbackQuery` (attrs + `AsyncMock` for `.answer`/`.edit_text`) + `FSMContext` over `MemoryStorage`. No live Bot/TG. Merge gate: `ruff` + `ruff format` + `mypy bot` clean on new files (repo baseline has ~24 mypy / ~83 ruff pre-existing in OTHER files — add none); full `pytest` green.
- UI language: Russian, button-first (mirror `bot/keyboards.py`, `bot/rendering.py`). Cyrillic RUF001 in new files: match the existing repo convention (those rules already fire repo-wide; keep new files consistent, do not add `# noqa` noise beyond what the repo already tolerates — if ruff flags Cyrillic in new files, that mirrors baseline and is acceptable, but keep `ruff format` clean).

```python
# bot/botui/middleware.py
"""Per-update DB session: one transaction per Telegram update."""

from __future__ import annotations

from collections.abc import Awaitable, Callable
from typing import Any

from aiogram import BaseMiddleware
from aiogram.types import TelegramObject
from sqlalchemy.ext.asyncio import AsyncSession, async_sessionmaker

Handler = Callable[[TelegramObject, dict[str, Any]], Awaitable[Any]]


class DbSessionMiddleware(BaseMiddleware):
    """Open one AsyncSession per update; commit on success, rollback on error."""

    def __init__(self, sessionmaker: async_sessionmaker[AsyncSession]) -> None:
        self._sessionmaker = sessionmaker

    async def __call__(
        self, handler: Handler, event: TelegramObject, data: dict[str, Any]
    ) -> Any:
        async with self._sessionmaker() as session:
            data["session"] = session
            try:
                result = await handler(event, data)
            except Exception:
                await session.rollback()
                raise
            await session.commit()
            return result
```

**Interfaces (all `async def`, first arg `session: AsyncSession`):**

- `archive_account(session, user_id, account_id: int) -> bool` — set status `archived` for that user's account; return whether a row changed.

```python
# bot/botui/repository.py
"""Async DB access for the self-service cabinet. Decimal money; thin over models."""

from __future__ import annotations

from datetime import date
from typing import Any

from sqlalchemy import select, update
from sqlalchemy.exc import IntegrityError
from sqlalchemy.ext.asyncio import AsyncSession

from bot.db.models.identity import ExchangeAccount, User, Wallet
from bot.db.models.ops import AuditEvent


async def upsert_user(session: AsyncSession, user_id: int) -> User:
    user = await session.get(User, user_id)
    if user is None:
        user = User(id=user_id, role="user", status="active")
        session.add(user)
        await session.flush()
    return user


async def get_active_wallet(session: AsyncSession, user_id: int) -> Wallet | None:
    stmt = select(Wallet).where(Wallet.user_id == user_id, Wallet.status == "active")
    return await session.scalar(stmt)


async def replace_wallet(
    session: AsyncSession,
    user_id: int,
    *,
    address_encrypted: bytes,
    address_hash: bytes,
    address_masked: str,
) -> Wallet:
    await session.execute(
        update(Wallet)
        .where(Wallet.user_id == user_id, Wallet.status == "active")
        .values(status="replaced", replaced_at=func.now())
    )
    wallet = Wallet(
        user_id=user_id,
        chain="BEP20",
        address_encrypted=address_encrypted,
        address_hash=address_hash,
        address_masked=address_masked,
        status="active",
    )
    session.add(wallet)
    await session.flush()
    return wallet


async def add_account(
    session: AsyncSession, user_id: int, exchange: str, uid: str, accrual_since: date
) -> ExchangeAccount | None:
    existing = await session.scalar(
        select(ExchangeAccount).where(
            ExchangeAccount.exchange == exchange, ExchangeAccount.uid == uid
        )
    )
    if existing is not None:
        return None  # first-come: taken (by anyone)
    account = ExchangeAccount(
        user_id=user_id, exchange=exchange, uid=uid, status="active", accrual_since=accrual_since
    )
    session.add(account)
    try:
        await session.flush()
    except IntegrityError:
        await session.rollback()
        return None  # race: someone claimed it between check and insert
    return account


async def list_accounts(session: AsyncSession, user_id: int) -> list[ExchangeAccount]:
    stmt = (
        select(ExchangeAccount)
        .where(ExchangeAccount.user_id == user_id, ExchangeAccount.status == "active")
        .order_by(ExchangeAccount.id)
    )
    return list((await session.scalars(stmt)).all())


async def archive_account(session: AsyncSession, user_id: int, account_id: int) -> bool:
    result = await session.execute(
        update(ExchangeAccount)
        .where(
            ExchangeAccount.id == account_id,
            ExchangeAccount.user_id == user_id,
            ExchangeAccount.status == "active",
        )
        .values(status="archived")
    )
    return (result.rowcount or 0) > 0


async def write_audit(
    session: AsyncSession,
    *,
    actor: str,
    action: str,
    entity_type: str,
    entity_id: str | None = None,
    new_value: dict[str, Any] | None = None,
) -> None:
    session.add(
        AuditEvent(
            actor=actor,
            action=action,
            entity_type=entity_type,
            entity_id=entity_id,
            new_value=new_value,
        )
    )
    await session.flush()
```

```python
# bot/botui/service.py
"""aiogram-free application logic for the cabinet. Decimal money throughout."""

from __future__ import annotations

import hashlib
import re

from sqlalchemy.ext.asyncio import AsyncSession

from bot.botui import repository as repo
from bot.security.secrets import SecretCipher

_ADDRESS_RE = re.compile(r"^0x[0-9a-fA-F]{40}$")


class AddressError(ValueError):
    """The submitted wallet address is not a valid BEP20 (EVM) address."""


def validate_address(raw: str) -> str:
    addr = raw.strip()
    if not _ADDRESS_RE.match(addr):
        raise AddressError("Адрес должен быть в формате 0x + 40 hex-символов.")
    return addr.lower()


def mask_address(addr: str) -> str:
    return f"{addr[:6]}…{addr[-4:]}"


def address_hash(addr: str) -> bytes:
    return hashlib.sha256(addr.lower().encode("utf-8")).digest()


async def set_wallet(
    session: AsyncSession, cipher: SecretCipher, user_id: int, raw: str
) -> str:
    addr = validate_address(raw)
    encrypted = cipher.encrypt(addr).encode("ascii")
    masked = mask_address(addr)
    await repo.replace_wallet(
        session,
        user_id,
        address_encrypted=encrypted,
        address_hash=address_hash(addr),
        address_masked=masked,
    )
    await repo.write_audit(
        session,
        actor=str(user_id),
        action="wallet_replaced",
        entity_type="wallet",
        entity_id=str(user_id),
        new_value={"masked": masked},
    )
    return masked
```

```python
from __future__ import annotations

from aiogram import F, Router
from aiogram.fsm.context import FSMContext
from aiogram.types import CallbackQuery, Message
from sqlalchemy.ext.asyncio import AsyncSession

from bot.botui import service
from bot.botui.keyboards import CabinetCB
from bot.botui.states import WalletFlow
from bot.security.secrets import SecretCipher

router = Router(name="botui-wallet")


@router.callback_query(CabinetCB.filter(F.action == "wallet"))
async def prompt_wallet(callback: CallbackQuery, state: FSMContext) -> None:
    await state.set_state(WalletFlow.waiting_address)
    await callback.message.answer(
        "Пришлите ваш <b>BEP20 (BSC)</b> адрес (0x…). Он заменит текущий."
    )
    await callback.answer()


@router.message(WalletFlow.waiting_address, F.text)
async def receive_wallet(
    message: Message, state: FSMContext, session: AsyncSession, cipher: SecretCipher
) -> None:
    try:
        masked = await service.set_wallet(session, cipher, message.from_user.id, message.text)
    except service.AddressError as exc:
        await message.answer(f"⚠️ {exc}\nПопробуйте ещё раз или /cancel.")
        return
    await state.clear()
    await message.answer(f"✅ Кошелёк сохранён: <code>{masked}</code>")
```
